# WinGet Plugin Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans in this session.

**Goal:** Install missing WinGet packages through an optional plugin.
**Architecture:** Mirror npm bundle boundaries and shared native execution.
Use JSON export and reconcile exact IDs against fresh state.
**Tech Stack:** Python 3.9+, standard library, unittest, Ruff, mypy.
**Spec:** ../specs/2026-10-28-winget-design.md

## Global Constraints

Python 3.9+, standard library only; API 1; no upgrades or removals.

## Review Focus

Malformed inventory fails before installs; apply bypasses snapshot caches;
empty requests launch no commands; partial failures allow safe reapply;
package IDs and target options never become arbitrary flags.

Files: plugins/winget/{__init__,etch_plugin,schema,cli,action,facts}.py;
